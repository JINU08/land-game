# 땅따먹기 배틀 : LAND CONQUEST 🚩

1 VS 1 턴제 전술 6x6 보드 게임 웹 애플리케이션입니다.

## 🎮 게임 소개
- **6x6 전술 보드**: 상대방과 영토를 차지하고 점수를 겨루는 땅따먹기 배틀
- **사운드 & 애니메이션 효과**: Web Audio API 기반의 효과음 및 시각 효과 탑재
- **반응형 웹 디자인**: 모바일 및 데스크톱 환경 지원

## 🚀 실행 방법

### 로컬 실행
별도의 빌드 과정 없이 `index.html` 파일을 브라우저로 직접 열거나 로컬 개발 서버를 실행할 수 있습니다.

```bash
# 로컬 개발 서버 실행
npm run dev
# 또는
npx serve . -l 5173
```
브라우저에서 `http://localhost:5173` 접속

## 🛠 기술 스택
- HTML5 / Vanilla JavaScript (ES6+)
- CSS3 (Custom Design System, Responsive)
- Web Audio API (Synthesizer Sound Effects)
